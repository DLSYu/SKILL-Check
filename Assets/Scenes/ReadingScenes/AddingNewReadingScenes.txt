PYTHON DEPENDENCIES
1. Install Miniconda
2. Make an environment using conda create --name spacy
3. conda activate spacy "spacy" can be anything btw its just a name
4. Install spacy using the settings you pick here
   - if you have a gpu i recommend using cuda
   - https://spacy.io/usage
5. Sanity check: Run the python script
   - go to directory with pos-gen.py
   - python pos-gen.py "I am under a tree"
6. Make sure the filepaths are current in PartOfSpeechGen.cs
